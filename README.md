# Un día en El Quillay de Pirque (versión 2)

Web de arriendo de piscina y terraza en Pirque, contada como un día completo de 10:00 a 20:00.
El cielo cambia con el scroll (mañana, tarde, atardecer y noche) y un reloj marca la hora.

## Qué tiene
- Intro de amanecer con la mascota (una vez por visita, se puede saltar)
- Foto del inicio con efecto de agua (WebGL) que reacciona al mouse o al dedo
- Tarjetas apiladas con cada espacio, galería que se arrastra, calculadora de reserva con mensaje listo para WhatsApp
- Noche con guirnaldas que se encienden y luciérnagas

## Archivos
- `index.html` — toda la página
- `assets/img/` — fotos (mismos nombres que la versión clásica)
- `.nojekyll` — publica los archivos tal cual en GitHub Pages

Para cambiar una foto, reemplaza el archivo en `assets/img/` con el mismo nombre.
